`loadSnapshot` in `src/store/snapshot.ts` ([Snapshot persistence](/components/snapshot-persistence.md)) returns null silently on every failure. Keep returning null (the store then refreshes from the network), but stay silent only for a missing file (ENOENT); log a warning for unreadable files, invalid JSON, an unknown version and a corpus that lacks the object-valued sources `buildIndex` reads (players, events, results, manifest, points).
